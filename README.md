# Sales Data Dashboard

An interactive Power BI dashboard analyzing sales performance across products, customers, and regions. Built to turn raw transactional sales data into decision-ready views for executives and analysts.

**[View the live dashboard](https://app.powerbi.com/groups/me/reports/0c47fcec-d704-4686-b4a9-244db13fe3c7/b263e49fd53802a6c9d8?experience=power-bi)**

> Note: the live link requires Power BI workspace access. See screenshots below for a full preview.

## Overview

This report consolidates sales data into four connected pages, letting users move from a high-level executive summary down to individual product and customer detail.

## Pages

**Executive Dashboard** — Top-level KPIs: total revenue, profit, orders, and trends over time. The entry point for leadership.

**World Map** — Geospatial view of sales by region, surfacing geographic concentration and underperforming markets.

**Product Detail** — Revenue, profit, and volume broken down by product and category.

**Customer Detail** — Customer-level performance, segmentation, and top-account analysis.
